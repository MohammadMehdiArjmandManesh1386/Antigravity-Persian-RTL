## ✨ ویژگی‌های کلیدی

- ⚡ **فوق‌العاده سبک و پرسرعت (Ultra-Fast Engine - 120 FPS)**: بدون استفاده از MutationObserver سنگین، رندرینگ متون به صورت مستقیم توسط شتاب‌دهنده کرومیوم با خواص بومی direction: auto و unicode-bidi: plaintext انجام می‌شود.
- 🎨 **پیش‌نمایش و سوییچ زنده فونت‌ها**:
  - امکان انتخاب قلم و مشاهده پیش‌نمایش در نرم‌افزار نصاب قبل از نصب.
  - دکمه اختصاصی **[🎨 فونت]** در بالای برنامه جهت تغییر آنی قلم به **وزیرمتن**، **استودیو**، **ری** یا **صمیم** بدون نیاز به ریستارت.
- 📊 **راست‌چین‌سازی کامل جدول‌ها (Markdown Tables)**: ستون اول در سمت راست قرار گرفته و متون با تراز راست و فونت استاندارد نمایش می‌یابند.
- 🔢 **اصلاح چینش لیست‌های شماره‌دار**: شماره‌ها (1., 2., ...) دقیقاً در سمت راست و چسبیده به متن بدون فاصله اضافه قرار می‌گیرند.
- 🕒 **فارسی‌سازی خودکار زمان‌ها**: زمان‌های گفتگوها (14h, 7d, 1mo, 29m, 
ow) به صورت خودکار به ۱۴ ساعت پیش، ۷ روز پیش، ۱ ماه پیش، ۲۹ دقیقه پیش و همین الان با ارقام فارسی تبدیل می‌شوند.
- 🛡️ **حفاظت ۱۰۰٪ از کدها و ترمینال**: تمام بلوک‌های کدنویسی (pre، code، خروجی ترمینال و توکن‌ها) به صورت کاملاً چپ‌چین (LTR) با فونت تخصصی برنامه‌نویسی بدون تغییر باقی می‌مانند.
- 🔒 **نصاب مستقل بدون پیش‌نیاز (Zero Dependency Standalone EXE)**: نرم‌افزار نصاب فقط ~۱۰۰ کیلوبایت حجم دارد و با استفاده از معماری بومی .NET ویندوز بدون نیاز به پایتون یا Node.js کار می‌کند.
- ↩️ **سیستم پشتیبان‌گیری و بازگردانی امن**: ایجاد خودکار فایل بکاپ pp.asar.backup با قابلیت بازگردانی به نسخه اولیه کارخانه با یک کلیک.

## 🚀 دانلود و نصب سریع

### روش ۱: استفاده از فایل اجرایی نصاب (پیشنهادی)
1. از بخش **[Releases](../../releases)** آخرین نسخه فایل Antigravity-Persian-Installer.exe یا فایل زیپ Antigravity-Persian-RTL.zip را دانلود کنید.
2. فایل نصاب را اجرا کرده و فونت مورد نظر خود را انتخاب نمایید.
3. روی دکمه سبز رنگ **«نصب و فعال‌سازی فارسی‌ساز»** کلیک کنید.
4. دکمه **«راه‌اندازی مجدد برنامه»** را بزنید تا برنامه با ظاهر جدید اجرا شود.

### روش ۲: اسکریپت سریع (Batch)
- برای نصب سریع: فایل Install-Persian-RTL.bat را اجرا کنید.
- برای بازگردانی به نسخه اصلی: فایل Uninstall-Persian-RTL.bat را اجرا کنید.

## 🎨 فونت‌ها و قلم‌های پشتیبانی‌شده

این بسته شامل ۴ فونت پرطرفدار و استاندارد فارسی است:

| نام فونت | سبک و ویژگی | کاربرد پیشنهادی |
| :--- | :--- | :--- |
| **وزیرمتن (Vazirmatn)** | مدرن، خوانا، بهینه‌سازی‌شده برای صفحات وب و کدنویسی | رابط کاربری عمومی و مطالعه طولانی |
| **استودیو (SD-Studio)** | بولد، شیک، گرافیکی و خاص | عناوین، تیترها و محیط‌های مدرن |
| **ری (Ray)** | هندسی، نوآورانه و متوازن | پروژه‌های خاص و طراحی مینیمال |
| **صمیم (Samim)** | کلاسیک، ساده و روان | متون اداری و مستندات |

> **نکته:** در داخل محیط برنامه، با کلیک روی دکمه **[🎨 فونت]** در نوار بالای صفحه می‌توانید در هر لحظه فونت را تغییر دهید.

## 🛠️ ساخت و کامپایل از سورس کد

پروژه به صورت یک فایل مستقل سی‌شارپ طراحی شده که با کامپایلر پیش‌فرض خود ویندوز (csc.exe) کامپایل می‌شود.

برای کامپایل دستی کافیست فایل uild.bat را اجرا کنید یا دستور زیر را در خط فرمان وارد نمایید:

`cmd
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /target:winexe /win32icon:assets\app_logo.ico /out:Antigravity-Persian-Installer.exe /r:System.Windows.Forms.dll,System.Drawing.dll,System.Web.Extensions.dll src\AntigravityPersianInstaller.cs
`

## 🌐 English Summary

**Antigravity Persian RTL** is a high-performance, standalone zero-dependency installer and runtime enhancer for the Google DeepMind Antigravity developer environment.

### Features:
- **100% Native RTL BiDi Layout** leveraging Chromium's internal layout engine with zero UI lag (120 FPS).
- **Embedded Font Manager**: Includes Vazirmatn, SD-Studio, Ray, and Samim with in-app real-time font switching.
- **Markdown Tables & Lists RTL Alignment**: Proper right-aligned list numbering and table headers.
- **Smart Relative Timestamp Localization**: Automatically translates elapsed times to Persian digits and relative phrases.
- **Zero External Dependencies**: Compiled into a single, standalone ~100 KB executable using native Windows .NET components.
